# DOLLZ WORLD — Y2K Adventure

Небольшой браузерный платформер на HTML, CSS и ванильном JavaScript (ES-модули + Canvas). Игровой движок, npm и сборщик не используются.

## Запуск
Откройте `index.html` в браузере. Если браузер блокирует ES-модули при открытии файла напрямую, запустите локальный сервер из папки проекта:
- Python: `python -m http.server 8000`
- Затем откройте `http://localhost:8000`

## Управление
- `←` / `→` или `A` / `D` — движение
- `Space` или `W` — прыжок (только с платформы)
- На телефоне — экранные кнопки внизу экрана
- Кнопки PAUSE и RESTART — пауза и перезапуск

## Цель
Соберите три аксессуара (сумочка, очки и бриллиант), затем доберитесь до финиша. Падение в опасную зону или за пределы уровня приводит к поражению. Лучший результат сохраняется в `localStorage`.

## Структура
- `index.html` — интерфейс
- `style.css` — адаптивное оформление
- `js/main.js` — запуск, UI и единый игровой цикл
- `js/Game.js` — уровень, состояние, отрисовка и игровой процесс
- `js/Player.js` — движение и физика персонажа
- `js/input.js` — клавиатура и сенсорное управление
- `js/collision.js` — столкновения

## Технологии и игровой цикл
Canvas 2D, `requestAnimationFrame`, `dt`, классы ES6, события клавиатуры и Pointer Events, `localStorage`, `visibilitychange`. Игровой цикл один; время кадра ограничено, а после скрытия вкладки игра ставится на паузу.

## Проверка перед сдачей
Проверьте прохождение уровня, сбор всех трёх предметов, падение в опасную зону, паузу, рестарт несколько раз подряд, переключение вкладок, сенсорные кнопки и сохранение рекорда после перезагрузки.

## Использованные материалы
Графика персонажа, окружения, платформ и предметов нарисована кодом Canvas. Внешние изображения и аудио не используются. Шрифт загружается через Google Fonts; при отсутствии сети применится системный sans-serif.
